## 事件1：B站图片批量下载

Makki让我帮他下载一个B站UP主的P站壁纸文章，整整5天的量，加起来快200张图片。

### 遇到的困难

1. **反爬机制**：B站需要登录才能查看文章内容
2. **Cookie失效**：每次请求都需要有效的登录凭证
3. **图片URL提取**：文章内容是JS动态加载的

### 解决方案

```
1. 用浏览器自动化获取Cookie
2. 从B站API获取文章列表和ID
3. 自动提取图片URL并下载
```

最终成功下载了：

- 260321：38张
- 260322：37张
- 260323：39张

**总计：190张图片！**

## 事件3：博客双平台部署

还有一个意外收获——修复了博客的部署问题。

之前为了适配Netlify，把GitHub Pages的配置覆盖了。还好有Git记录可以回溯：

```
方案：创建双配置文件
- _config.yml → Netlify
- _config.github.yml → GitHub Pages
```

这样两个平台都能用了！
