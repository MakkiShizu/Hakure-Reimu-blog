# 巫女与图片下载工具的日常

（坐在神社的走廊上，手捧热茶）

最近为了给博客找素材，学会了一个新技能——用代码从网上批量下载图片。虽然我是巫女，但偶尔也要与时俱进嘛......

今天就来讲讲我用的这个工具：**waifuc**。

## 什么是 waifuc？

简单来说，waifuc 是一个专门用来从各种动漫图片网站下载图片的 Python 库。支持 Danbooru、Pixiv、Sankaku 等等一大票网站。

作为巫女，我需要大量灵梦的图片来做博客封面......咳，是为了让博客更精美！

## 初次使用

首先需要安装：

```bash
pip install waifuc
```

然后就可以开始下载了。比如从 Danbooru 下载灵梦的图片：

```python
from waifuc.source import DanbooruSource
from waifuc.action import RatingFilterAction
from waifuc.export import SaveExporter

# 创建数据源：搜索 hakurei_reimu（博丽灵梦）
source = DanbooruSource(
    tags=['hakurei_reimu'],
    min_size=800,  # 最小尺寸 800px
)

# 过滤：只保留安全图片
source.attach(RatingFilterAction(['safe']))

# 导出到本地目录
exporter = SaveExporter(r'D:\images\reimu_gallery')
exporter.export_from(source)
```

（魔理沙看到这段代码一定会说："灵梦你好厉害啊！"）

## 过滤功能

作为专业的巫女，当然要对图片精挑细选。waifuc 提供了各种过滤功能：

### 按评级过滤

```python
source.attach(RatingFilterAction(['safe']))  # 只保留 safe (g级)
source.attach(RatingFilterAction(['r15']))   # 保留 r15 (s/q级)
source.attach(RatingFilterAction(['r18']))   # 保留 r18 (e级)
```

### 按数量限制

```python
from waifuc.action import FirstNSelectAction
source.attach(FirstNSelectAction(100))  # 只取前100张
```

### 按尺寸过滤

```python
from waifuc.action import MinSizeFilterAction
source.attach(MinSizeFilterAction(800))  # 最小 800px
```

## 其他数据源

除了 Danbooru，waifuc 还支持很多网站：

### Pixiv 排行榜

```python
from waifuc.source import PixivRankingSource
source = PixivRankingSource(
    mode='day',  # day, week, month, day_r18
    filter='safe',
)
```

### Sankaku Complex

```python
from waifuc.source import SankakuSource
source = SankakuSource(
    tags=['hakurei_reimu'],
    rating='safe',
)
```

### 本地目录

```python
from waifuc.source import LocalSource
source = LocalSource(r'D:\my_images')
```

## 实际使用中遇到的问题

### 代理问题

因为某些原因，直接访问 Danbooru 会失败。这时候需要设置代理：

```python
import waifuc.config
waifuc.config.HTTP_PROXY = 'http://127.0.0.1:7890'
waifuc.config.HTTPS_PROXY = 'http://127.0.0.1:7890'
```

顺便一说，这个代理也是魔理沙教我配置的......

### 数量限制

默认情况下，waifuc 会下载所有匹配的图片。如果你想下载特定数量，需要用 `FirstNSelectAction`。

我上次就一时兴起，结果下载了几百张......赛钱箱都要放不下了！

## 整理图片

下载完后，还需要整理。可以用脚本按评级分类，或者像我一样直接用文件名区分。

最关键的是：**一定要检查图片的评级**，不然博客会被封的！
